zenbridge

Let Claude Code drive your real, logged-in Zen Browser or Firefox: open tabs, read pages, click, type, scroll and take screenshots, only in tabs you hand it.

Install add-on · v__VERSION__

Signed by Mozilla. Zen or Firefox 140+. If the browser asks, choose Continue to installation, then Add.

Then install the companion app

The add-on talks to Claude Code through a small Python app on your computer (macOS or Linux, Python 3.10+):

git clone https://github.com/Jprdgza/zenbridge.git
cd zenbridge && ./install.sh

Restart the browser, open a new tab, click the zenbridge button and choose Turn Claude on.
